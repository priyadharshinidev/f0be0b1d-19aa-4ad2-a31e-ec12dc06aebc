Longest Increasing Sequence — Implementation Guide

Goal: Implement a public C# method that takes a single string of integers (space-separated) and returns the longest contiguous strictly increasing sequence as a single space-separated string. If multiple sequences of equal length exist, return the earliest one.

Will the proposed approach work?

The required behavior is a longest contiguous increasing run, so a single linear scan is sufficient. A general subsequence algorithm would produce different results because it may skip values.

Flow (mapping to your diagram)

    INPUT
      ↓
    Parse integers
      ↓
    For each adjacent pair (index i - 1, i)
      ↓
    If nums[i] > nums[i - 1], extend current run
      ↓
    Otherwise, start a new run
      ↓
    Update the best run only when the current run is longer
      ↓
    Join the selected values
      ↓
    RESULT

Data structures to maintain

  • nums[] — parsed integers
  • bestStart and bestLength — the selected run
  • currentStart — the start of the run currently being scanned

Tie-breaking (earliest sequence)

Update the best run only when the current run is strictly longer. Equal-length runs do not replace it, so the first longest run is preserved.

Because the result must be contiguous, no predecessor array or patience-sorting tails are needed.

Pseudocode

parse input -> nums[] (ignore empty tokens)
if nums is empty, return empty string
bestStart = 0; bestLength = 1; currentStart = 0
for i in 1..nums.length - 1:
  if nums[i] <= nums[i - 1]: currentStart = i
  currentLength = i - currentStart + 1
  if currentLength > bestLength:
    bestStart = currentStart; bestLength = currentLength
join nums[bestStart..bestStart + bestLength - 1] with single spaces

Complexity

  • Time: O(n)
  • Space: O(n) for the parsed values

Edge cases

  • Empty input -> return empty string
  • Single number -> return that number
  • Duplicate or decreasing adjacent values end the current run
  • Leading/trailing/multiple spaces: trim and split on whitespace

Recommendation

Use the linear adjacent-value scan. It directly matches the contiguous sequence requirement and preserves the earliest longest run.
